# Courses Platform Prototype

A small React/Vite prototype of an interactive course-enrollment panel, built for Nielsen Norman Group’s Senior Frontend Developer exercise. It lets users:

- **Select** a class date via radio-style cards  
- **Enroll** in the currently selected date  
- **Save** (favorite) the course for later  

Built with TypeScript, Vite, Tailwind-like CSS variables, and the [Intl API](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl).

---

## ⛏️ Tech Stack

- **Framework:** React 18 + Vite  
- **Language:** TypeScript  
- **Styling:** CSS custom properties (tokenized in `theme.css`)  
- **Formatting:** `Intl.DateTimeFormat` for consistent dates/times  
- **Bundler:** Vite  

---

## 🚀 Getting Started

1. **Clone the repo**  
   ```bash
   git clone https://github.com/your-username/courses-platform-prototype.git
   cd courses-platform-prototype

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Launch the dev server**

   ```bash
   npm run dev
   ```

4. Open in browser at http://localhost:5173/

### Build for production

   ```bash
   npm run build
   ```
